LeRobot HuggingFace 모델 목록 정리

출처: huggingface.co/lerobot — 총 38개 모델 (2026-04-22 기준) 프로젝트 조건: mycobot280 / pick & place / 6-DOF 관절 제어 / RealSense fine-tuning 예정

모델 선정 기준

기준 내용
태스크 pick & place (물체 집어서 옮기기)
액션 공간 6-DOF 관절 각도 (joint position)
학습 데이터 RealSense RGB-D로 직접 수집 → fine-tuning
하드웨어 mycobot280 + Raspberry Pi / Jetson

프로젝트 추천 모델 (우선순위 순)

★ 1순위 — act_aloha_sim_transfer_cube_human

가장 조건에 맞는 베이스모델.

항목 내용
태스크 블록 집어서 이동 → pick & place와 동일 구조
액션 공간 ALOHA 로봇팔 관절 각도 — mycobot280과 구조 동일 (6-DOF)
학습 데이터 실제 로봇팔 시연 데이터 (human demonstration)
Fine-tuning RealSense 데이터로 from scratch 학습 — 아키텍처 참고용
주의 ALOHA = 14-DOF (bimanual), mycobot280 = 6-DOF → pretrained weight 직접 이전 불가 
# phase4_train.sh — pretrained 없이 from scratch
--policy.type=act
--dataset.repo_id=data/mycobot_lerobot

act_aloha_sim_insertion_human은 커넥터 삽입 특화라 pick & place보다 적합도 낮음.

★ 2순위 — pi05_base (또는 pi0fast-base)

Generalist policy — 다양한 manipulation 태스크에 사전학습됨.

항목 내용
태스크 pick & place 포함 다양한 manipulation
액션 공간 범용 (관절 각도 지원)
학습 데이터 대규모 실제 로봇 데모 데이터
Fine-tuning 소량 데이터로도 효과적 (generalist 특성)
추론 속도 pi0fast-base 선택 시 엣지 디바이스에 적합 
--policy.type=pi0
--policy.pretrained=lerobot/pi05_base

Jetson/Raspberry Pi 배포 고려 시 pi0fast-base 선택.

3순위 — smolvla_base

경량 VLA — 엣지 배포 우선일 때.

항목 내용
태스크 범용 (VLA벤치마크 기반)
액션 공간 범용
특징 모델 크기 작음, 추론 빠름
단점 pick & place 특화 사전학습 없음 → 더 많은 fine-tuning 데이터 필요

ACT (act_aloha_*) — 2개

Action Chunking with Transformers. ALOHA 실제 로봇 하드웨어 demonstration 기반.

모델 태스크 프로젝트 관련
act_aloha_sim_transfer_cube_human 블록 집어서 이동 1순위 후보
act_aloha_sim_insertion_human 커넥터 삽입 pick & place와 태스크 다름

Diffusion Policy (diffusion_*) — 2개

관측값 → Denoising diffusion → 행동 시퀀스.

모델 설명 프로젝트 관련
diffusion_pusht 2D T블록 밀기 (pusht 태스크) 비적합 — 2D 태스크, 관절 제어 아님
diffusion_pusht_keypoints keypoint 기반 변형 비적합

pusht 계열은 2D end-effector 제어 전용 — mycobot280 관절 제어와 액션 공간 불일치.

VQ-BeT (vqbet_pusht) — 1개

Vector Quantized Behavior Transformer. pusht 태스크 전용 — 비적합.

FAST (fast-action-tokenizer) — 1개

행동 시퀀스를 토큰으로 변환하는 모듈. 단독 사용보다 다른 모델(π0 등)과 결합해서 사용.
